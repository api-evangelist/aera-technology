> maintained by API Evangelist, not by Aera Technology — Aera publishes no llms.txt of its
> own (https://www.aeratechnology.com/llms.txt returns 404).

## What is publicly callable

Aera Decision Cloud's API reference is **not public**. https://docs.aeratechnology.com/ is a
Document360 site that 302-redirects to Aera's identity provider
(idp-dev.aeratechnology.com), so the product API contract requires a customer login. No
OpenAPI, AsyncAPI, GraphQL SDL, Postman collection or JSON Schema is published anywhere we
could find, and github.com/aeratechnology has zero public repositories.

One machine surface is publicly discoverable: an **authenticated MCP server** on the
corporate host.

## APIs

- [Aera Technology MCP Server](https://www.aeratechnology.com/wp-json/mcp/mcp-oauth-server): JSON-RPC Model Context Protocol endpoint on the corporate WordPress host. Anonymous `tools/list` returns HTTP 401 `mcp_unauthorized`; a bearer token with the `mcp` scope is required.

## Discovery

- [OAuth protected resource metadata](https://www.aeratechnology.com/.well-known/oauth-protected-resource): RFC 9728 — names the MCP resource and its authorization server.
- [OAuth authorization server metadata](https://www.aeratechnology.com/.well-known/oauth-authorization-server): RFC 8414 — authorization_code + refresh_token, PKCE S256, public client, single `mcp` scope.
